Executar o sistema localmente com Electron

Contexto

O sistema guarda dados de clientes, valores de serviços, despesas e relatórios financeiros. A operação prevista ocorre em uma estação de trabalho. Restringir a execução à própria máquina reduz a exposição pela rede.

Decisão

Distribuir um instalador para Windows x64 com React, Express e PostgreSQL. O Electron inicia e encerra a API e o banco, sem Docker. A API aplica as migrações antes de aceitar requisições.

A API e o banco escutam apenas em 127.0.0.1, em portas escolhidas na abertura. A janela usa gestao://local, sandbox e isolamento de contexto. O processo principal encaminha as chamadas à API com uma chave gerada a cada execução.

A API valida o login e exige uma sessão para acessar os dados. Existe uma única conta local, com senha predefinida e sem cadastro ou troca de senha pela interface. O banco guarda um hash com sal, derivado por scrypt. As sessões ficam em memória e são invalidadas ao sair do aplicativo.

Alternativas consideradas

O Docker Compose oferece uma execução local pelo navegador com banco separado. Uma implantação em rede ou em hospedagem remota exigiria rever autenticação, permissões e proteção do tráfego.

Consequências

Os dados persistem em %LOCALAPPDATA%\GestaoServicosDados. Faça backups da pasta com o aplicativo fechado. O PostgreSQL usa uma senha aleatória guardada no perfil do Windows.

A senha predefinida é destinada ao uso individual. O login não criptografa a base nem substitui o bloqueio do Windows, as permissões de arquivos e a proteção dos backups.
